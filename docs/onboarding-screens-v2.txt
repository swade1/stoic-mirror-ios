THE STOIC MIRROR — ONBOARDING SCREENS V2
==========================================
Based on Screensdesign research: prove value fast, one lightweight preference,
defer sign-up, gate monetization on intent.

ANALYSIS OF CURRENT FLOW vs SCREENSDESIGN GUIDELINES
======================================================

Current flow (5 screens):
1. The Problem — "Your mind won't stop"
2. The Insight — Epictetus/Aurelius
3. The Practice — Daily Stoic practice
4. The Tool — How the app works
5. The Promise — Equanimity

Problems with current flow:
- 5 screens is too many before proving value
- No personalization/preference collection
- Sign-up happens before user experiences anything
- No paywall — monetization not addressed
- Heavy on philosophy, light on "what's in it for me right now"

NOTES ON KEY CHANGES
=====================

1. SCREENS REDUCED: 5 philosophy screens → 2 value/proof screens
   Reason: prove value fast, don't lecture before user is invested

2. PERSONALIZATION ADDED: "What brings you here?" preference screen
   Reason: lightweight, one question, makes app feel tailored
   Implementation: store answer as first category preference

3. SOCIAL PROOF SCREEN: replaces 3 philosophy explanation screens
   Reason: DailyCare shows social proof alone can substitute for
   feature tour when step budget is tight
   Note: need real user quotes before launch — use placeholder for now

4. PAYWALL REPOSITIONED: before sign-up, after intent established
   Reason: gate on intent not on launch. User has seen value prop,
   personalized their experience, seen social proof — now they're
   ready to decide

5. SIGN-UP DEFERRED: moved to after paywall decision
   Reason: removing friction early increases completion rate.
   User who decides to subscribe is highly motivated to complete sign-up

6. PAYWALL FRAMED AS PATRONAGE: "Support the practice" not "Subscribe"
   Reason: Meditate app uses this framing successfully. Feels less
   transactional, more aligned with the app's philosophical values

7. FREE OPTION PRESERVED: "Maybe later — continue free"
   Reason: Art of Living uses intent-driven model with no hard paywall.
   Users who try free and find value convert later.

Implementation Notes 
Free session tracking:
- Track session count in AsyncStorage (no account needed)
- Increment on each "Seek Counsel" tap
- Check count before navigating to loading screen
- If count >= 3 and not subscribed → show paywall
- Note: session count resets on uninstall/reinstall — accepted
  risk. Users who game the free tier are unlikely to convert
  to paying customers. Reducing friction for the honest majority
  outweighs the cost of occasional abuse.
